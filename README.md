## 当前项目概览

LightRAG Agentic Knowledge Base 是一个基于 LightRAG 构建的企业级知识库系统，支持：

- 多格式文档解析与异步索引
- 图谱 + 向量混合检索
- Agentic 查询消解、查询改写与检索评分
- 带引用溯源的问答
- 多部门 / 多工作空间隔离
- 长对话上下文记忆

如需查看完整架构、能力说明和启动方式，请直接阅读 [LightRAG_Project/README.md](LightRAG_Project/README.md)。
